# Standalone source-reference Hoare reasoning

## Scope and notation

This is implementation-grounded reasoning for the source-reference modules and their runtime wiring, not a machine proof, resource guarantee, or evidence that a model chooses useful citations. Let `CP(s) = Array.from(s)`, `C` be a `SourceCollection`'s flattened dense chunks, and `join` concatenate strings. Callers establish trusted nominal `SourceIndex | SourceCollection`, JavaScript strings, and collection density; the parser does not accept arbitrary resolver callbacks.

## Construction and rendering

`createChunks(source, firstId)` requires a string and caller-established integer first ID. Its outer-unit invariant is `join(emitted) + pending = processed source prefix`, `offset = |join(emitted)|`, and pending is the only un-emitted suffix. Its `append` loop preserves order one code point at a time and decreases remaining characters. Its `emit` NSP for nonempty pending records `id = firstId + emitted.length`, local `[offset, offset + pendingLength)`, then clears pending; the empty NSP preserves the invariant. Thus `SourceIndex.from` establishes IDs from 1, while `SourceCollection.from` establishes global density by carrying `firstId = 1 + prior flattened count` across its block map loop.

For each physical unit, the blank branch flushes only before an oversized indivisible blank run, then appends it whole. The normal branch either appends a fitting line, flushes/reconsiders a nonfitting pending chunk, or invokes `splitLength` with fresh bounds. `splitLength`'s candidate-loop invariant is that earlier candidates in `[L,k)` are ineligible; it returns the first eligible boundary or the CRLF-safe fallback. The normal-line inner loop measure is lexicographic `(remaining code points, pending nonzero)`: flushing decreases the second component, splitting decreases the first, and append exits. The outer measure is remaining units. For `firstId = 1` and three physical units of lengths 70, 100, and 80 (so these IDs use `L = 80, U = 160`), the outer-unit invariant has traces `(emitted lengths, pending length, offset) = ([], 70, 0)`, `([70, 100], 0, 170)`, and `([70, 100, 80], 0, 250)` after each iteration. Each trace preserves the processed-prefix partition and advances the outer measure by one unit. Therefore chunk texts partition the original block and all ID-sensitive bounds use the actual next global ID.

`SourceCollection.from`'s map invariant is that completed block lists preserve positions, partition each completed source independently, and `firstId` is one plus their flattened count. Empty source advances neither count nor ID. Snapshot getters map private records to fresh records, so external mutation cannot alter lookup state. `renderAnnotatedBlocks` maps each block; its inner-loop invariant is the exact labels plus escaped raw chunks already processed. The nonempty NSP appends one `@!@`; the empty NSP returns `""`. Preparation, not `renderAnnotated`, is the complete model-input layer, so every active prepared block is terminated even for one block.

## Parser and expansion

`parseSliceInteger` either returns an omitted endpoint at a permitted terminator or consumes one signed decimal into `bigint`; its digit-loop invariant is the consumed syntactic prefix. `parseSlice` accepts exactly one `:` or `..` separator and a closing bracket. `parseOperations` has invariant `value = initial after exactly consumed text operations`; every accepted slice/method advances `next`, and `.trim()` selects the same Python-whitespace operation as `.strip()`. It stops before `.pos()`, and `finish` accepts that projection only when it is terminal immediately before the closing `@`.

`parseEndpoint` validates a positive decimal ID against `chunkCount` before safe conversion and returns its independently transformed source value. For `X~Y`, both IDs validate before `rangeValue` traverses from first to last; reversed ranges throw before traversal. `rangeValue`'s invariant is that its result contains the sourced values for IDs already visited, and its `id += 1n` step advances to the next dense ID, giving progress under finite trusted `chunkCount`. For a grouped raw range 1..3 with chunks `a`, `b`, and `c`, its three iterations trace `(id, text) = (1, "")`, `(2, "a")`, `(3, "ab")`, and `(4, "abc")`; each step appends the current dense chunk and decreases the finite remaining-range measure. Unparenthesized ranges concatenate transformed endpoints around raw interiors. Equal IDs re-run the right operation chain on the left value, so it is selected once. Grouped ranges require unmodified endpoints, concatenate their raw inclusive range, then run only outer operations. Any missing operand, malformed separator/group, nesting/chaining suffix, unknown ID, unsupported operation, or nonterminal `.pos()` throws `DraftExpansionError` from the strict parser.

A sourced value maintains `text.length in code points = sum(span.end - span.start)`. `sliceSourcedValue` intersects one normalized output interval with each ordered span; `stripSourcedValue` derives such an interval by scanning Python whitespace; `joinSourcedValues` concatenates text and merges only adjacent spans in the same block. `formatSourcePosition` branches to the empty or cross-block unavailable messages, otherwise maps the bounding first and final selected offsets into 1-based lines and 0-based code-point columns. Its source scan advances one code point per iteration and treats CRLF as one transition.

`expandDraft`'s invariant is `expanded = one-pass tolerant decode(draft[0, offset))`. Its ordinary, escaped-literal, valid-reference, and invalid-reference NSPs append their defined output and strictly advance `offset`; the invalid branch catches only `DraftExpansionError`, consumes through the first closing `@` or draft end, and appends one unresolved diagnostic containing that complete candidate. With source chunk `@!2@` and draft `x@|!@!1@`, the three loop iterations trace `(offset, out) = (0, "")`, `(1, "x")`, `(4, "x@!")`, and `(8, "x@!@!2@")`; each state satisfies the decoded-prefix invariant and decreases `draft.length - offset`. The measure proves termination on parser-valid and parser-invalid drafts alike; unrelated exceptions still propagate. Reference output has no edge back to parser control flow, proving no recursive interpretation.

## Preparation and composition

`prepareSourceReferences` scans all blocks while establishing all-text/string eligibility and at least one nonempty source. Its inactive NSP shallow-copies blocks without indexing/escaping. Its active NSP builds aligned sources, collection, and annotated copies; rewritten `text` is constructively `string`, while other generic metadata is preserved. No literal original text refinement is asserted for annotated data. The function retains no global state or input mutation.

`runSourceReferencePipeline` prepares before selecting ON/OFF instructions, so the same `active` state controls annotation, prompt capability, and expansion. The passthrough NSP returns before draft interpretation. For active note drafts, tolerant expansion returns valid substitutions plus explicit unresolved diagnostics; citation mistakes do not select a citation-error branch; later exact-empty and whole-note-length branches still apply. Exact `""` selects empty, `>= originalLength` selects failing, and only the remaining success reaches `formatSourceReferenceNote`. That formatter's callback traversal replaces placeholders once after `template.trimEnd()`, so `$` data and final raw note whitespace are not rescanned or removed.

Representative unrolls: (1) global ID 9 emits under a four-code-point label and ID 10 recomputes a five-code-point label; (2) `@!3[2..]~7.trim()@` independently transforms raw endpoints and traverses raw IDs 4–6; (3) `@!(3~7).trim()[1..-1]@` concatenates raw IDs first, then applies outer operations; (4) a raw returned `<think>@!1@\r\n` is appended once and receives no cleanup.

## Executable evidence and limits

Focused node:test coverage includes original construction/escaping cases, global 9→10/99→100 line-budget cases, collection snapshots, eligibility, position projection, unresolved diagnostics/OFF literals, final-note CRLF whitespace, 2,500 deterministic generated collection cases, 10,000-digit IDs, 256-reference amplification, and range grouping/precedence/aliases/malformed cases. The generated cases and probes demonstrate tested finite behavior only; hidden serialization, provider behavior, semantic source selection, and universal allocation/amplification bounds remain outside this reasoning.
